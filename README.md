## 📌 Project Overview

The **IPL Performance Analysis Dashboard** is an interactive Excel-based data analytics project created to analyze IPL match data from **2008 to 2019**.

The dashboard transforms raw IPL data into interactive visualizations and KPI cards, allowing users to explore different aspects of IPL performance.

### The dashboard covers:

- 🏏 Team Performance
- 📅 Season-wise Analysis
- 🪙 Toss Decisions
- 🏟️ Venue Analysis
- 👥 Player Distribution
- 4️⃣ Boundary Analysis
- 📈 Average Run Rate
- 📊 Match Statistics

# 🔍 Analysis Performed

## 1. 🏏 Team Performance Analysis

The dashboard compares team performance across selected seasons and matches.

It helps explore:

- Team wins
- Match results
- Team-vs-team performance
- Season-wise performance

---

## 2. 🪙 Toss Decision Analysis

The dashboard analyzes toss decisions made by teams throughout different IPL seasons.

The analysis includes:

- Bat first
- Field first
- Season-wise toss decisions
- Toss decision trends

---

## 3. 🏟️ Popular Playground Analysis

The dashboard identifies venues where IPL matches were frequently played.

This analysis provides insights into:

- Popular venues
- Number of matches played
- Venue distribution

---

## 4. 👥 Player Analysis

The project includes player-level information and visualizations related to IPL matches.

The dashboard explores:

- Player of the Match
- Player distribution
- Match-related player information

---

## 5. 4️⃣ Boundary Analysis

The dashboard visualizes boundary-related statistics.

It includes:

- Number of 4s
- Number of 6s
- Boundary distribution

This helps explore scoring patterns in IPL matches.

---

## 6. 📈 Average Run Rate

The dashboard presents run-rate trends across IPL seasons.

This allows users to explore how scoring rates changed across different seasons.

# 🧠 Methodology — CRISP-DM

The project follows a simplified **CRISP-DM (Cross Industry Standard Process for Data Mining)** methodology.

### 1️⃣ Business Understanding

The objective was to analyze IPL match data and understand:

- Team performance
- Player involvement
- Toss decisions
- Venue popularity
- Scoring patterns

### 2️⃣ Data Understanding

The available datasets contain information related to:

- Matches
- Teams
- Players
- Toss decisions
- Match results
- Venues
- Deliveries
- Runs

### 3️⃣ Data Preparation

The raw datasets were organized and prepared for analysis.

Relevant data was structured so that it could be used for calculations, PivotTables, charts, and dashboard visualizations.

### 4️⃣ Analysis

Microsoft Excel was used for:

- Data aggregation
- Excel formulas
- PivotTables
- Calculations
- KPI generation
- Trend analysis

### 5️⃣ Visualization

The analyzed data was converted into:

- Interactive charts
- KPI cards
- Comparison charts
- Trend charts
- Dashboard components

### 6️⃣ Insights

The final dashboard provides an interactive way to explore IPL trends and relationships within the dataset.
